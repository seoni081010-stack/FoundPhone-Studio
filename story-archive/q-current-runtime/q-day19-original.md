## 第 1 段 · 14:00 · 门厅

```text
午后，你刚走出门厅，一颗雪球就从石阶下飞了上来，擦过扶手，碎在墙边。
下面有人喊：“没打中！”
池昌民站在石阶另一侧，低头拍着袍子上的雪。
池昌民：打中了。你刚才打的是我。
他拍了拍袖口，朝台阶下喊。
池昌民：英宰，你刚才还说你要进去了。
孙英宰：我是准备进去了啊。
池昌民转头看你。
池昌民：五分钟前他也是这么说的。
石阶下几个人笑起来。他听见你的脚步声，转过头，把刚捏好的雪球放在栏杆上。
同学：昌民，现在你可以找个队友了。
池昌民看向你。
池昌民：你跟我一边吗？
```


```text
你：行。你还有雪球吗？
池昌民指了指栏杆。
池昌民：就这一颗。
你弯腰拢了一捧雪。他刚想把栏杆上那颗递给你，一颗雪球就砸在你们中间。两个人同时缩了一下手。
你：你从那头过去。我在这儿。
他拿着雪球绕到栏杆另一侧。你一探头，下面的人果然跟着转了过来。池昌民趁那人回头，一球打中了他的袍角。
你刚举起手想跟他击掌，就见他朝你身后一指。
池昌民：后面！
你俩连手都没碰到，又各自蹲了回去。
```

#### B · 好感度 +1 · `q-day19-stage0-1`

```text
我去他们那边。你现在认输还来得及。
```

```text
你：我去他们那边。你现在认输还来得及。
池昌民看着你下了两级台阶，把栏杆上的雪球拿了起来。
池昌民：你先走远一点再说。
你听见这句，立刻往下一跳。雪球擦过你身后的石阶，碎在你刚才站的地方。
你在台阶底下抓了把雪，转身扔回去，正中他的袖子。
池昌民低头看了一眼，抬起手。
池昌民：等一下，我投降。
你刚把手放下，他已经弯腰抓了一把雪。
你：你不是投降了吗？
池昌民：你也没说同意啊。
```

## 第 2 段 · 14:00 · 门厅

```text
等你们停下来，最先动手的同学已经坐在台阶上，把手套里的雪往外倒。
有人提议回礼堂喝点热的。几个人往门厅走，你落在后面，弯腰抖了抖袍角。池昌民走到门边，回头问你。
池昌民：一起进去？
```

```text
去啊。我手都冻僵了。
```

```text
你：去啊。我手都冻僵了。
池昌民替你撑住门。
池昌民：那你先进去，我去拿杯子。
你在长桌边坐下，没一会儿，他端着两杯热饮回来。你刚想接离自己近的那杯，他把两杯换了个位置。
池昌民：拿这杯。刚倒的。
```

#### B · 好感度 +1 · `q-day19-stage1-1`

```text
你们先进去，我把鞋上的雪弄掉。
```

```text
你：你们先进去，我把鞋上的雪弄掉。
池昌民低头看了看自己的靴子，也在门边停下来。
池昌民：那我也弄一下。
门里的人喊你们快来，说再不进来就要把热的喝完了。
池昌民一边跺脚，一边冲里面喊了一声。
池昌民：留两杯！
等你们进去，长桌边已经空出了两个位置，杯子也摆好了。
```

## 第 3 段 · 15:00 · 大礼堂

```text
你刚喝了一口，就听见对面又争了起来。最先扔雪球的同学坚持说，他那一颗谁也没打中。
池昌民端着杯子，转头看你。
```

#### A · 好感度 +1 · `q-day19-stage2-0`

```text
刚才在门口，我可听见有人说打中了。
```

```text
你：刚才在门口，我可听见有人说打中了。
池昌民点了点头，伸手指向自己袍子上那块还没干的水印。
池昌民：听见了吧？我还有证据。
同学：你这儿至少挨了三下，谁知道是哪一下。
池昌民低头看了看那块水印，自己先笑了。
```

#### B · 好感度 +2 · `q-day19-stage2-1`

```text
你们下次还打吗？
```

```text
你：你们下次还打吗？
池昌民：打啊。你来吗？
你抬眼看他。他把杯子放下来，又补了一句。
池昌民：下次我早点问你跟谁一边。
对面的人立刻接话，说他们也可以先问。池昌民笑着往椅背上一靠，把这个问题留给了你。
```

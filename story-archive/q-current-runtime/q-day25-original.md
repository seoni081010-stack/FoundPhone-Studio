## 第 1 段 · 10:00 · 门厅

```text
你从礼堂出来时，池昌民正蹲在门廊边上，拿一根枯枝拨弄台阶上的雪。
你走近一看，雪里有两排细小的脚印。那枚从棋盘上溜走的黑国王站在脚印尽头，积雪已经没过了它的腰。
黑国王：再往左一点。那边浅。
池昌民：你刚才也说这边浅。
他把枯枝横在雪面上。黑国王两手抱住树枝，还没站稳，就顺着枝条滑了回去。
池昌民抬头看见你，把枯枝往旁边放了放。
池昌民：圣诞快乐。你来得正好。
```


```text
你：你扶着它。我给它挖条路。
你捡起枯枝，从台阶边往里划开一道窄沟。池昌民用两根手指扶住黑国王的肩，等它自己一步一步走出来。
黑国王刚踏上干地，就回过头看了看那条路。
黑国王：再宽一点。明天我还要走。
池昌民：你倒是先问问她明天来不来。
他侧过脸看你。黑国王也跟着转过身，他伸手把它转了回去。
```

#### B · 好感度 +1 · `q-day25-stage0-1`

```text
你们怎么走到雪里去了？
```

```text
你：你们怎么走到雪里去了？
池昌民：它说想看看雪。我就把它搁在台阶上，回去拿了条围巾。
他用枯枝拨开最后一点积雪，黑国王踩着枝条爬上来。
黑国王：我以为底下有地。
池昌民把它托在掌心，轻轻抖掉它王冠上的雪。
池昌民：昨天还嫌我口袋闷。现在肯回去了吗？
黑国王背过身，自己钻进了他的口袋。
```

## 第 2 段 · 10:15 · 城堡外的小路

```text
你们沿着城堡外墙慢慢走。转过拐角，风小了些，石墙根下还留着一片没人踩过的雪。
池昌民走了几步，回头看了一眼。你的脚印和他的隔得很近，有两个已经叠在了一起。
池昌民：我昨天回去以后，还在想一件事。
他把手从口袋里抽出来，又低头把围巾松了松。
池昌民：今天早上我下楼的时候，又往昨天等你的地方看了一眼。
```

#### A · 好感度 +2 · `q-day25-stage1-0`

```text
我也看了。下到一半才想起来，今天没约你。
```

```text
你：我也看了。下到一半才想起来，今天没约你。
他停下来，回头看你。
池昌民：那我们今天约一下？
你们离城堡门口也就十几步。他朝那边看了看，自己先笑了。
池昌民：已经碰见了。那就约明天吧。
```

#### B · 好感度 +1 · `q-day25-stage1-1`

```text

```

```text
你：那你下次可以叫我下来。
池昌民：早一点也行？
你：先说说有多早。
他想了想，往你这边走了一步。
池昌民：等南瓜汁端出来以后。你慢慢下来，我给你留一杯。
```

## 第 3 段 · 10:15 · 城堡外的小路

```text
城堡里传来开门声，黑国王从他口袋里探出头，催他回去找壁炉。池昌民按住口袋边，等它缩回去，才看向你。
池昌民：再走一小段？它在我口袋里，冻不着。
```

#### A · 好感度 +2 · `q-day25-stage2-0`

```text
走吧。前面还没人踩过。
```

```text
你：走吧。前面还没人踩过。
你先迈进雪里，走了两步，回头等他。池昌民低头看了看你留下的脚印，挑了旁边那块雪踩下去。
这一次，你们的脚印一直并排到了拐角。
```

#### B · 好感度 +1 · `q-day25-stage2-1`

```text
走慢一点。我鞋里进雪了。
```

```text
你：走慢一点。我鞋里进雪了。
池昌民停在墙边，等你把鞋里的雪磕出来。再往前走时，他就跟在你身侧，踩雪的声音一轻一重。
你们沿着外墙绕回门口。他推开门，口袋里的黑国王立刻探出头，朝礼堂壁炉的方向看。
池昌民：走吧，陪它烤会儿火。
他扶着门等你进去。礼堂靠窗的位置还空着，你们就坐过去，把那枚冻了一早上的黑国王搁在了两只杯子中间。
```

## 第 1 段 · 15:00 · 图书馆

```text
你翻到书的下一页时，桌角响了两声。
那只黄铜甲虫从一本书底下钻出来，径直走向你的羽毛笔。你伸手压住笔杆，它却绕到另一侧，在桌面上敲了两下，便停住了。
池昌民从书架后面探出头。
池昌民：这次它没拿吧？
你：没有。它敲桌子了。
他抱着书走过来，在你对面坐下。
池昌民：我把那个地方改了。找到东西就敲两下，等人来拿。
池昌民压低声音。
池昌民：我刚才拿给俊英看，他以为它敲两下是饿了，还问我它吃什么。
你：你怎么说？
池昌民：我说它吃羽毛笔。他就把自己的笔收起来了。
甲虫又敲了一次。隔壁桌有人抬头，池昌民赶紧伸出一根手指，按住它的背。
池昌民：两下就够了。
```

## 第 2 段 · 15:00 · 图书馆

```text
池昌民翻开本子。第一页还是那几只画得不太一样的甲虫。往后翻了几页，你看见一根细长的羽毛笔，笔杆上有一道磨掉的金漆。
你把自己的笔摆过去，两道缺口几乎在同一个地方。
池昌民：上次你说它可能是认错了金漆，我回去照着画了一遍。后来我找了三支差不多的笔，它都没认出来。
你：那你怎么让它今天找到的？
他从你的笔尖旁边指过去。甲虫抬起前脚，碰了碰笔杆上一处很浅的凹痕。
池昌民：这里。它记得第一次碰到的是哪里。
```

```text
你：那你教教我，怎么让它找点别的。
他把本子往你面前推了推，起身换到了你旁边的椅子上。
池昌民：你先挑一样。挑个小的。
你从书里抽出一张纸条。池昌民低头看你在纸上折了一道角，才把自己的魔杖放到桌面上。
池昌民：你来。我在这儿看着。
```

#### B · 好感度 +1 · `q-day28-stage1-1`

```text
我把笔藏起来，你让它再找一次？
```

```text
你：我把笔藏起来，你让它再找一次？
池昌民：好。那我也不看。
他真把脸转向了书架。你把笔夹进摊开的书里，只露出一小截笔杆。
甲虫爬过两本书，停在你的手边。它敲了两下。
池昌民转回来，先看见你的手，再看见你手底下露出的那截笔。
池昌民：怪不得。我还以为它今天找的是你。
他说完低头把甲虫接回掌心。你把笔从书里抽出来，这次没急着收进笔袋。
```

# Layered Marauder's Map

This update uses the user's supplied castle cutaway as a spatial reference. The picture has no numbered floor boundaries, so the main building is presented as four map levels: 1 entrance hall/Great Hall/trophy room/armour corridor; 2 Defence Against the Dark Arts/library/History of Magic/activity room/restricted library section; 3 Transfiguration/hospital/Muggle Studies/empty classrooms/Myrtle's bathroom/one-eyed witch passage; 4 Charms/prefect bathroom/Ancient Runes/Arithmancy. This is the game's reading of that illustration, not a claim that every book/film edition uses identical floor numbering. Explicit floor names in existing authored story locations are respected.

Basement rooms (Potions, kitchens, Hufflepuff/Slytherin common rooms), high rooms/towers (Astronomy, North Tower Divination, Gryffindor/Ravenclaw common rooms, headmaster's office, Room of Requirement, West Tower owlery and observatory) and grounds remain separate. Snape's office and the Chamber of Secrets are absent. No story manuscripts, timetable attendance IDs, affinity, gifts, album/mail data or save keys are changed.

`castleFloors.ts` centralizes floor layouts, subject-to-classroom mappings and narrative aliases. All 16 scheduled subjects resolve to named rooms rather than a corridor fallback. Study/research/advice entries use the library. Character routines still use each character's own timetable and authored itinerary; an active story override applies only to the selected character. Explicit story floors take precedence for named corridors/exhibition/empty-room locations.

The existing parchment/oath/erase/audio interaction is retained. The user's follow-up explicitly requests exclusive floor views instead of the earlier continuous overview: navigation contains only 一层、二层、三层、四层、地窖、高层与塔楼、室外, with no full-map tab, people totals or per-floor count badges. Each tab renders only that floor and its present characters. All seven remain in the underlying location model and can be found by changing floors. This user preference supersedes the earlier simultaneous-all-markers display. No activity roster is added outside the drawing.

Each floor reuses the original 360×565 castle silhouette, double walls, interior corridor/stairs, secret passage, sketch rooms and ink/footstep effects. The old coordinate metadata API remains available for route validation, while `castleFloorPoint` projects floor-aware room locations onto the original drawing. The header continues to describe only the selected character's actual location, even when viewing another floor.

A newly started timetable lesson takes over from an earlier authored scene’s two-hour location window. A scene beginning at or after that lesson, or the selected route's explicit active-story place, still takes precedence. This fixes pre-class staircase markers remaining there after a new class starts.

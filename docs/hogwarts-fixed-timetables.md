# 霍格沃茨固定课表：四学院 × 五六七年级

> 游戏原创的12套预设课表，不代表原著官方课表。玩家创建身份后按学院和年级自动读取，不提供自由选课或「选择下一节课」按钮。时间为游戏内时间。

## 全局规则
- 每日固定 09:00、11:00、14:00 三个日间时段；周末不安排常规课程。
- 五年级参加 O.W.L. 课程；六、七年级参加预设 N.E.W.T. 进阶科目（游戏简化版本，实际进阶资格可作为剧情设定）。
- 选修A、B由系统预设，不由玩家临时决定。六、七年级的课程安排为游戏简化设计，并非所有学生都必须修相同科目。
- 「自习与作业」「导师答疑」「毕业研究」「N.E.W.T.复习」不是教授授课的正式科目。
- 同年级格兰芬多与斯莱特林共用基础课程时间；拉文克劳与赫奇帕奇共用另一组时间，避免基础课程冲突。选修课可以按各学院独立分班。
- 天文学五年级周三 20:00 统一安排观测；六七年级若剧情需要可安排特定晚间观测活动，不默认每周必修。
- 学生会、魁地奇训练和比赛不占用固定课堂时间；活动与课程冲突时须明确调整。
- 本课表不自动确定男主选课。男主与玩家的课堂相遇必须额外核对人物选课和对应分组，不能只因同年级就出现。
- 教师随选定故事时代替换，尤其魔药学、黑魔法防御术、占卜学、麻瓜研究。

## 运行时实现要求
1. 创建角色后由 `year + house` 读取唯一课表。
2. 游戏时钟到达课程时段自动打开当前课程事件；玩家只选择课堂内的行动/对话，不选择下一门课程。
3. 无课时段可探索地点；缺席课程若允许，必须有缺勤后果和剧情记录，而非自由换课。
4. 课堂偶遇检查 `year, subject, time, teachingGroup, characterEnrollment` 五项条件。
5. 必修主线与固定课程冲突时，在课间或课后排队触发。

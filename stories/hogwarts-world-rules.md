# 霍格沃茨世界观硬约束（所有路线通用）

- 故事发生于霍格沃茨魔法世界，禁止 Instagram、TikTok、X、Spotify、微信、KakaoTalk、现代手机、现代网络社交平台、视频通话、推送通知、现代购物和电子设备。
- 不能简单把现代 App 改名为魔法 App，交互行为本身必须符合魔法世界。
- 角色交流仅采用合理的魔法便笺、猫头鹰、当面交谈等方式；不出现现代即时通讯软件。
- FoundPhone Studio 仅为开发框架名称，并非故事里真的存在现代手机。
- 引擎内部 message 动作仅为数据事件，不代表故事里的手机短信。
- 角色学院、年级、级长职责、魁地奇、圣诞留校必须符合已经确认的设定。
- 未经用户许可，不公开部署。

## 未完成的世界观适配
现有运行时仍使用现代手机 UI，当前故事也依赖通用 messages、contacts、calendar、notes、photos、settings 入口。这些只能用于内部结构测试，不能作为最终预览或成品。必须在正式预览前更换为符合魔法世界的界面与交互机制。

## 验收
所有新剧情和 UI 必须排查现代软件名称、电子设备、网络社交行为和不符合魔法世界的通讯方式。
